# Checklist

## 项目结构
- [ ] 项目包含函数、数据库、UI 三段结构
- [ ] 顶部悬浮胶囊状 Top 栏可切换"函数 / 数据库 / UI"
- [ ] 切换三段时各自编辑状态独立保留

## 函数组织
- [ ] 函数支持命名、重命名
- [ ] 函数支持多标签
- [ ] 文件夹支持子文件夹无限嵌套
- [ ] 支持按名称 / 标签 / 文件夹路径检索函数

## 节点系统（双平面模型）
- [ ] 节点图编辑器可缩放、平移、放置节点、拖拽节点
- [ ] 画布连线仅承载控制流（执行顺序+分支），无数据端口、无类型校验、无扇出节点
- [ ] 节点可点击进入节点编辑页配置参数与 `#` 引用
- [ ] 节点按配置动态声明命名输出（控制流输出 + 数据输出）
- [ ] DAG 防环校验生效
- [ ] 变量节点（设置 / 读取）可用
- [ ] 运算节点（算术 / 逻辑 / 字符串）可用
- [ ] 流程控制节点（If 可配置任意 case / Loop body+completed 等命名输出）可用
- [ ] 数据库节点（增删改查 + 表结构操作）可用
- [ ] 函数调用节点可调用项目内其他函数

## 变量引用（数据平面）
- [ ] 节点编辑页参数输入框输入 `#` 弹出变量选择卡片
- [ ] 卡片按来源分组（控制流上游节点输出 / 函数变量 / 项目变量）
- [ ] 卡片显示类型提示，支持搜索过滤
- [ ] 两段式选择（节点→输出名）或 `#名称` 直接命中
- [ ] 输入 `#变量名` 可直接引用
- [ ] 变量名跨来源冲突时列候选并标注来源
- [ ] 可选变量 = 沿控制连线反向传递闭包可达的节点命名数据输出 + 函数变量 + 项目变量
- [ ] 循环体内变量仅在循环内可见
- [ ] 命名数据输出声明原始类型（number/string/bool/any）
- [ ] `#` 引用类型与目标参数不匹配时在节点编辑页内提示

## UI 编辑器与函数触发
- [ ] UI 段提供组件面板与画布
- [ ] 可拖拽放置组件并调整位置 / 尺寸 / 属性
- [ ] 组件属性可 `#` 绑定到函数命名输出或项目变量
- [ ] 点击组件显示其支持的触发点（点击/加载/卸载/列表项滚动到此处等）
- [ ] 组件触发点可绑定到函数（触发执行）
- [ ] 定时器 / 外部事件 / 函数调用节点可作为函数 entry

## 插件系统
- [ ] 插件节点抽象（输入 / 输出 / 配置声明）已定义
- [ ] 插件可加载与注册
- [ ] 插件配置（如 API Key）本地安全存储
- [ ] LLM 插件封装 OpenAI SDK（对话补全 / 流式）
- [ ] LLM 插件封装 Anthropic SDK（消息 / 流式）

## 多端编译打包
- [ ] 项目可转为完整 IR（覆盖函数 DAG / DB schema / UI tree / 变量）
- [ ] IR → Flutter/Dart 源码生成器可用
- [ ] IR 完整性校验（类型、引用）生效
- [ ] 一键编译 Web 产物（HTML/JS 静态包）
- [ ] 一键编译 Android 产物（APK）
- [ ] 一键编译 Windows 产物（可执行 / 可运行目录）
- [ ] 编译全程端侧完成，不依赖云服务
- [ ] 产物可本地导出 / 分享

## Android 兼容
- [ ] 应用作为移动端软件运行于 Android
- [ ] 核心功能（节点编辑 / UI 编辑 / 编译打包）在 Android 上均可用
- [ ] 适配不同 Android 屏幕尺寸与方向
- [ ] 触屏交互（节点拖拽、画布手势、卡片选择）针对移动端优化
