# Checklist

## 版本隔离
- [ ] 0.x 代码已归档到 legacy/v0 分支
- [ ] pubspec.yaml 版本号已升至 1.0.0
- [ ] 旧项目格式在 1.0 中无法打开（无向后兼容）

## 页面-组件强绑定
- [ ] 不创建页面时，组件添加入口禁用或提示"请先创建页面"
- [ ] 不允许通过任何途径创建游离组件（API、拖拽、粘贴均禁止）
- [ ] Page 作为 UI 树的根节点（type='page'）
- [ ] 所有组件必须以某 Page 为祖先（pageId 必填）
- [ ] Page 不可被删除（除非是项目唯一页面）
- [ ] Page 不可被移动、不可嵌套

## Page 作为特殊组件类型
- [ ] Page 有自己的参数段（name/route/isHome/背景/安全区/转场动画）
- [ ] Page 的布局段只读（固定填充屏幕 width=100%, height=100%）
- [ ] Page 有样式段（页面级样式 + 转场动画）
- [ ] Page 有触发段（onLoad/onDispose/onResume/onPause 生命周期事件）
- [ ] Page 间通过 ui_navigate 节点跳转
- [ ] 其中一个 Page 标记为首页（isHome）

## 四段式属性面板
- [ ] 属性面板按"参数 / 布局 / 样式 / 触发"固定顺序组织
- [ ] 参数段展示组件特有配置项，支持 `#` 引用
- [ ] 布局段展示模式选择 + 9宫格选择器（相对）或 x/y 配置（绝对）+ 尺寸 + 外间距
- [ ] 样式段展示组件特有样式 + 必须包含动画配置区
- [ ] 触发段展示组件事件，可绑定函数

## 双模布局系统
- [ ] 每个组件独立选择相对布局或绝对布局（组件级）
- [ ] 同一父组件下不同子组件可采用不同布局模式
- [ ] 切换布局模式时尽量保留位置信息

## 相对布局（9宫格堆叠）
- [ ] 布局段展示3x3小框（9宫格可视化选择器）
- [ ] 点击某格表示将组件分配到对应堆叠队列
- [ ] 左上格：从上往下排，靠左，从上开始
- [ ] 上中格：从上往下排，居中，从上开始
- [ ] 右上格：从上往下排，靠右，从上开始
- [ ] 左中格：从左往右排，从左开始，上下居中
- [ ] 中心格：从中心往上或往下排（取决于放置位置），居中
- [ ] 右中格：从右往左排，从右开始，上下居中
- [ ] 左下格：从下往上排，靠左，从下开始
- [ ] 下中格：从下往上排，居中，从下开始
- [ ] 右下格：从下往上排，靠右，从下开始
- [ ] 中心格支持双向堆叠（用户放置位置决定向上或向下）
- [ ] 距离记录：记录距最近边的 PX 或百分比（默认百分比）
- [ ] 最近边算法：组件位置距父组件哪边最近即记录距那边的距离
- [ ] 用户可类似编辑 PPT 一样拖动组件，拖动后重新计算最近边
- [ ] 距离单位可在 PX 与百分比间切换

## 相对布局的尺寸与外间距
- [ ] 相对布局组件必须指定 width 和 height
- [ ] 尺寸单位可选百分比或 PX
- [ ] 百分比单位可设置 minPx 和 maxPx 上下限
- [ ] 渲染时按百分比计算但 clamp 到 [minPx, maxPx]
- [ ] 4方向外间距（上/下/左/右）可分别独立配置
- [ ] 每个外间距方向的单位可选 PX 或百分比
- [ ] 外间距默认值为 0

## 绝对布局（PPT式自由移动）
- [ ] 记录组件的 x、y 坐标（相对父组件左上角）
- [ ] 坐标单位可选 PX 或百分比（默认百分比）
- [ ] 组件尺寸配置同相对布局（width/height + 单位 + min/max Px）
- [ ] 拖动时组件自由移动（PPT式）
- [ ] 移动后更新 x/y 坐标
- [ ] 不进行最近边吸附（与相对布局的区别）

## 长按进入移动模式
- [ ] 长按手势触发移动模式
- [ ] 相对布局组件：长按后拖动调整堆叠队列顺序
- [ ] 绝对布局组件：长按后 PPT 式自由移动（改变 x/y）
- [ ] 拖动时有可视化反馈（插入位置提示、让位动画）
- [ ] 松手后停留在新位置

## 概念模型与实现分离
- [ ] 实现时不使用10个独立列表存储子组件
- [ ] 子组件存储为单一列表（children）
- [ ] 每个子组件 layout 配置含 mode + cell 字段
- [ ] 渲染时按 mode + cell 分组并按堆叠方向排序

## 动画系统
- [ ] 每个组件可配置入场动画（首次出现时触发）
- [ ] 每个组件可配置出场动画（消失时触发）
- [ ] 每个组件可配置触发动画（事件触发）
- [ ] 一个组件可配置多个触发动画（不同事件触发不同动画）
- [ ] 支持预设动画（fade/slide/scale/bounce/rotate/elastic 等）
- [ ] 预设可调参数：时长、延迟、缓动曲线、初始/最终值
- [ ] 支持关键帧自定义动画
- [ ] 关键帧编辑器含时间轴
- [ ] 关键帧可设置属性：位置/透明度/缩放/旋转
- [ ] 关键帧间支持缓动曲线配置
- [ ] 时间轴支持预览播放

## 展示类组件
- [ ] 文本组件：支持单行/多行/富文本三种模式
- [ ] 图片组件：支持本地上传/base64/URL 三种来源

- [ ] 图片组件：本地上传的资源随项目保存
- [ ] 视频组件：支持本地上传/base64/URL 三种来源
- [ ] 视频组件：支持进度条/控制栏/手势/自动播放/循环/静音等丰富选项
- [ ] 视频组件：支持 object-fit 切换
- [ ] 图标组件：支持用户上传/粘贴 SVG 代码/从内置库选择
- [ ] 图标组件：内置 Material Icons + Lucide 两套图标库
- [ ] 图标组件：用户可在两套图标库间切换
- [ ] 图表组件：支持柱状图/面积图/饼图/散点图/雷达图/热力图/漏斗图等
- [ ] 图表组件：基于 fl_chart 实现
- [ ] 图表组件：数据源支持 `#` 引用绑定数组
- [ ] 所有展示类组件都支持动画配置
